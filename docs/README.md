# Commonty docs

Commonty is a home server that a few households run together: photos,
files, films, passwords and games, on boxes the members own, reached
through one app.

These pages are in four parts:

- **Guide**: joining, signing in, your devices and leaving.
- **Services**: each part of Commonty, how to use it, and exactly how private it is.
- **Policies**: privacy, security and the terms of use.
- **Develop**: how the code works and how to change it.
