Installing

The AppImage needs no install: make it executable and run it. Android asks you, once, to allow installing from outside its store. There is no store listing, because this is not a product.

Checking what you downloaded

Every file here is named, with its SHA-256, in a manifest signed with the fleet's release key, the same key that signs what the boxes run. A file that is not in it is not offered. The code under each download is the start of that hash.

Built from the source at that commit, by commands you can run yourself.

The Windows installer includes WinFsp, Windows File System Proxy, copyright Bill Zissimopoulos, which lets your library appear as a drive, and rclone, which puts it there.
